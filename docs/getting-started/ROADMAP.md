# Hummingbird Roadmap

## M1: Foundation
- Common, Platform, Memory, Tensor structures. (Complete)

## M2: Compute & Graph
- Threadpool, execution graphs, scheduler. (Complete)

## M3: Runtime & Inference (Current)
- Runtime orchestrator, Tokenization, Adapter integration. (Complete via RFC-019)

## M4: Performance & Streaming (Next)
- Streaming engine (RFC-020).
- Paged KV Cache.
- AVX/SIMD CPU optimizations.

## M5: Acceleration
- CUDA and Metal backend integrations.
